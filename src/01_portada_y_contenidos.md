## NOTAS PARA EL FACILITADOR

**Duración:** El manual está diseñado para 8 sesiones de grupo (una por módulo). Puede extenderse a 10-12 sesiones si se desea mayor profundidad.

**Formatos posibles:**

- **Retiro intensivo** de fin de semana (Módulos 0-3 el sábado; 4-7 el domingo)
- **Serie mensual** de un módulo por mes durante 8 meses
- **Grupo semanal** de 8 semanas consecutivas
- **Estudio individual** a ritmo personal

**Material necesario por sesión:**

- Biblia (preferiblemente RVR1960 para concordancia con las citas)
- Diario personal de duelo (recomendado)
- Este manual (módulo correspondiente)

**El Módulo 7 es el módulo del facilitador.** Se recomienda leerlo primero, antes de comenzar el proceso con el grupo.
